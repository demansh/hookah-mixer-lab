# hookah-mixer-lab

Экспериментальный интерфейс Hookah Mixer. Здесь пробуем новые UX-идеи, не трогая основную версию
(https://demansh.github.io/hookah-mixer/).

**Сайт:** https://demansh.github.io/hookah-mixer-lab/

## Что сейчас есть
«Температура мастера»: один микс за раз, подбор только тапами.
1. Старт: два чипа-вкладки «Настроение» и «Вкус» (выбранная вкладка — в адресе, `?tab=taste`).
   «Настроение» — сетка эмодзи по одному на каждый из 114 образов ядра, вперемешку (порядок меняется при каждой
   загрузке), без подписей: название образа видно в заголовке карточки после тапа (и во всплывающей подсказке).
   «Вкус» — 102 аромата (без холодка) текстовыми чипами по 17 категориям с эмодзи-заголовками, по алфавиту.
   Один тап — сразу один микс; у микса «по вкусу» выбранный аромат закреплён ♡, а заголовка у карточки нет.
   Внизу, над шкалой, кнопка «🎲 Случайный микс».
2. Внизу всегда видна шкала-градусник 36,6° (классика) · 37,2° (эксперимент) · 38° (смелое): тонкая трубка,
   над ней градусы. Переключение мгновенно меняет микс; температуру можно выбрать и до старта.
3. Слева от градусника — аватарка мастера (эмодзи, подпись только во всплывающей подсказке):
   😌 / 🤒 / 🥴 — 36,6° / 37,2° / 38° (и на старте) · 😵 варианты кончились, по кругу · 🤨 ничего не нашлось.
   На каждое действие аватарка «пружинит».
4. У каждого аромата в карточке: слева ♡ — «оставить во всех миксах» (не больше трёх, включая холодок; при лимите
   свободные сердечки неактивны). ♡ не перезагружает микс: отметки применяются при следующем ↻ или смене
   температуры. Справа ✕ — убрать аромат из текущего микса: остальные остаются, на место убранного встаёт
   подходящий или он просто пропадает, проценты пересчитываются. Убранное видно чипами под карточкой, тап по чипу
   снимает исключение (микс пересчитывается заново).
5. Над шкалой две кнопки-иконки: 🗑 «Начать заново» — на старт, новое зерно и новый порядок чипов (температура
   сохраняется); ↻ «Другой микс» — следующий вариант, уже показанные для этого выбора пропускаются.
6. Назад — только кнопкой браузера (отменяет и ♡, и ✕). Состояние в адресе:
   `?s=mix&c=tropical-fruits&keep=mango&drop=coconut&lock=mango,lime&p=1&t=bold`;
   микс по вкусу — `?s=mix&from=flavor&keep=banana`.
7. Русский и английский: переключатель RU/EN в шапке. Первый раз язык берётся из браузера (русский → RU, иначе EN),
   выбор запоминается в `localStorage` (`hookah-mixer-lab:lang`). Названия ароматов, образов и пояснения к парам —
   из ядра (`label.en`, `phrases.en`, `note.en`); при переключении показывается тот же микс.

## Устройство
- GitHub Pages + Jekyll (только сборка страницы), Vanilla JS с ES-модулями без сборщика.
- Ядро (база знаний и движок подбора) — репозиторий `hookah-mixer-core`, лежит рядом: `../hookah-mixer-core`.
  В приложение попадает копией собранного `dist/` в `assets/core/`; руками `assets/core/` не правим.
- Подбор — `recommendSelection` ядра (с 0.2.0): `{ concepts: { id: 1 }, required, excluded, seed }`. Ядро отдаёт
  на страницу три микса по уровням, температура выбирает один из них (нет нужного уровня — ближайший).
- ✕ без изменений ядра: оставшиеся ароматы микса становятся «замком» (`lock` в адресе) и уходят в ядро как
  обязательные вместе с образом, убранный — в `excluded`. Берётся микс текущей температуры не больше исходного
  (ищется на первых 5 страницах; иначе — первый). Замок не показывается сердечками и снимается при ↻, смене
  температуры, возврате аромата из «Убрано», выборе образа и сбросе. Сверка по 114 образам × 3 уровня × каждый
  аромат: 1164 правки, 0 неудач; замена «один на один» или просто удаление — в 95,5% случаев.
- `assets/js/options.js` — температуры, вкладки старта, категории ароматов; `state.js` — состояние, адрес,
  выбор для ядра; `render.js` — старт (вкладки, эмодзи, ароматы), карточка, нижние кнопки, шкала;
  `i18n.js` — строки интерфейса на двух языках и выбор языка; `master.js` — аватарка мастера;
  `concept-emoji.js` — эмодзи образов (нет эмодзи — показывается чип с названием); `icons.js` — иконки Lucide
  (heart, x, trash, refresh-cw; лицензия в `assets/icons/LICENSE-lucide.txt`); `app.js` — загрузка каталога,
  история, сброс, удержание микса при ♡, пропуск показанных миксов, связка. `assets/css/main.css` — стили.

## Обновить ядро
```bash
(cd ../hookah-mixer-core && npm install && npm run build)
./tools/sync-core.sh        # путь к ядру можно переопределить: CORE_DIR=... ./tools/sync-core.sh
```

## Запустить локально
```bash
bundle install
bundle exec jekyll serve    # http://127.0.0.1:4000/hookah-mixer-lab/
```

## Публикация
GitHub Pages из ветки `master`, корень репозитория (Settings → Pages → Deploy from a branch).

## Общий origin с основной версией
Все сайты `demansh.github.io/*` живут на одном origin, поэтому `localStorage`, `sessionStorage`, cookies
и кэши общие с основным приложением. Ключи хранилища лаборатории — только с префиксом `hookah-mixer-lab:`.
Service worker, если появится, регистрировать со scope `/hookah-mixer-lab/`.
