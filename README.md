# hookah-mixer-lab

Экспериментальный интерфейс Hookah Mixer. Здесь пробуем новые UX-идеи, не трогая основную версию
(https://demansh.github.io/hookah-mixer/).

**Сайт:** https://demansh.github.io/hookah-mixer-lab/

## Что сейчас есть
«Температура мастера»: один микс за раз, подбор только тапами.
1. Старт: чипы всех 114 образов ядра вперемешку (порядок меняется при каждой загрузке). Один тап — сразу
   один микс. Внизу, над шкалой, кнопка «🎲 Случайный микс».
2. Внизу всегда видна шкала-градусник: 36,6° «Мастер спокоен» (классика), 37,2° «Мастер экспериментирует»,
   38° «Мастер бредит» (смелое). Переключение мгновенно меняет микс; температуру можно выбрать и до старта.
3. У каждого аромата в карточке: слева ♡ — «оставить во всех миксах» (повторный тап открепляет; не больше трёх,
   включая холодок; при лимите свободные сердечки неактивны), справа ✕ — убрать. Убранное видно чипами под
   карточкой, тап по чипу возвращает аромат.
4. На экране микса над шкалой две кнопки-иконки: 🗑 «Начать заново» — на старт, новое зерно и новый порядок
   чипов (температура сохраняется); ↻ «Другой микс» — следующий вариант с тем же выбором и температурой.
5. Назад — только кнопкой браузера. Состояние в адресе: `?s=mix&c=tropical-fruits&keep=mango&drop=coconut&p=1&t=bold`.

## Устройство
- GitHub Pages + Jekyll (только сборка страницы), Vanilla JS с ES-модулями без сборщика.
- Ядро (база знаний и движок подбора) — репозиторий `hookah-mixer-core`, лежит рядом: `../hookah-mixer-core`.
  В приложение попадает копией собранного `dist/` в `assets/core/`; руками `assets/core/` не правим.
- Подбор — `recommendSelection` ядра (с 0.2.0): `{ concepts: { id: 1 }, required, excluded, seed }`. Ядро отдаёт
  на страницу три микса по уровням, температура выбирает один из них (нет нужного уровня — ближайший).
- `assets/js/options.js` — температуры; `state.js` — состояние, адрес, выбор для ядра; `render.js` — старт,
  карточка, нижние кнопки, шкала; `icons.js` — иконки Lucide
  (heart, x, trash, refresh-cw; лицензия в `assets/icons/LICENSE-lucide.txt`);
  `app.js` — загрузка каталога, история, сброс, связка. `assets/css/main.css` — стили.

## Обновить ядро
```bash
(cd ../hookah-mixer-core && npm install && npm run build)
./tools/sync-core.sh        # путь к ядру можно переопределить: CORE_DIR=... ./tools/sync-core.sh
```

## Запустить локально
```bash
bundle install
bundle exec jekyll serve    # http://127.0.0.1:4000/hookah-mixer-lab/
```

## Публикация
GitHub Pages из ветки `master`, корень репозитория (Settings → Pages → Deploy from a branch).

## Общий origin с основной версией
Все сайты `demansh.github.io/*` живут на одном origin, поэтому `localStorage`, `sessionStorage`, cookies
и кэши общие с основным приложением. Ключи хранилища лаборатории — только с префиксом `hookah-mixer-lab:`.
Service worker, если появится, регистрировать со scope `/hookah-mixer-lab/`.
