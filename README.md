# hookah-mixer-lab

Экспериментальный интерфейс Hookah Mixer. Здесь пробуем новые UX-идеи, не трогая основную версию
(https://demansh.github.io/hookah-mixer/).

**Сайт:** https://demansh.github.io/hookah-mixer-lab/

## Что сейчас есть
Подбор микса только тапами, без клавиатуры:
1. Экран направлений: фрукты, тропики, цитрусы, десерты, коктейли, лимонады, пряности, травы и цветы,
   «удиви меня». Тап — сразу три микса: классика с изюминкой, эксперимент, смелое сочетание.
2. Тап по аромату в карточке: «📌 Оставить во всех» (до трёх, вместе с холодком) или «✕ Убрать».
3. Сдвиги вкуса: слаще, кислее, свежее, сливочнее, прянее, холоднее (= закрепить холодок).
4. Выбранное видно чипами сверху, тап по чипу снимает. «Ещё варианты» — следующие три микса (по кругу).
5. Всё состояние в адресе: `?d=tropics&keep=mango,cooling&drop=coconut&shift=sour&p=1` — «назад» работает.
«Хочу похожее» пока выключено — ждёт генератора соседей микса в ядре.

## Устройство
- GitHub Pages + Jekyll (только сборка страницы), Vanilla JS с ES-модулями без сборщика.
- Ядро (база знаний и движок подбора) — репозиторий `hookah-mixer-core`, лежит рядом: `../hookah-mixer-core`.
  В приложение попадает копией собранного `dist/` в `assets/core/`; руками `assets/core/` не правим.
- Тапы превращаются в текст запроса для `recommend` ядра: направление, закреплённые ароматы, сдвиги и в самом
  конце «без X» (отрицание в ядре действует на всё, что идёт после него).
- `assets/js/options.js` — направления, сдвиги, подписи уровней; `state.js` — состояние, адрес, сборка запроса;
  `render.js` — экраны; `app.js` — загрузка каталога, история, связка. `assets/css/main.css` — стили.

## Обновить ядро
```bash
(cd ../hookah-mixer-core && npm install && npm run build)
./tools/sync-core.sh        # путь к ядру можно переопределить: CORE_DIR=... ./tools/sync-core.sh
```

## Запустить локально
```bash
bundle install
bundle exec jekyll serve    # http://127.0.0.1:4000/hookah-mixer-lab/
```

## Публикация
GitHub Pages из ветки `master`, корень репозитория (Settings → Pages → Deploy from a branch).

## Общий origin с основной версией
Все сайты `demansh.github.io/*` живут на одном origin, поэтому `localStorage`, `sessionStorage`, cookies
и кэши общие с основным приложением. Ключи хранилища лаборатории — только с префиксом `hookah-mixer-lab:`.
Service worker, если появится, регистрировать со scope `/hookah-mixer-lab/`.
